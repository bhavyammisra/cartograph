Cartograph demo

Privacy

Last updated 29 October 2026

This demo is a static website. It shows a pre-built map of an open-source codebase and replays recorded searches. It does not run any AI model while you use it.

What this site collects

  • No accounts, forms or sign-in.
  • No cookies, analytics, advertising or tracking scripts.
  • Your searches run in your browser and are not sent anywhere.

Hosting

The site is hosted by Vercel, which, like any web host, processes basic request data (such as IP address and browser type) to deliver pages and keep the service secure. See Vercel's privacy policy.

The Cartograph tool

When you run Cartograph yourself, it works entirely on your own computer: your code is indexed into a local database and never uploaded.
